This is a free file in which you can, when activated, have a random skillcheck appear on your screen.
Skillchecks currently have a chance to trigger once between 1 second to 13 minutes. Pressing the "=" button will cause it to appear immediately so you can test it out whenever you want.

Use this with friends while playing other games or to mess with them as it forces them to input the spacebar and might scare them when they focus and forget about it. THIS IS MEANT TO BE A FUN ADDON TO GAMEPLAY! 
However, this is important, I DO NOT KNOW how this would react to anti-cheats as it is a python script converted with auto-py as an .exe. I would recommend being careful.

Here are the features!:
Negative Skillchecks - Merciless Storm, Caulrophobia, Unnerving Presence, Oppression, Huntress' Lullaby, and Madness.
Positive Skillcheck - This is not happening (Entity's Favor)
Modifier: Chaos Mode - Enable Caulrophobia, unnerving presence and Madness to all skillchecks.

Missing a skillcheck will block movement inputs for 2-3 seconds, and missing many in a row will increase the block up to 5 seconds (resets when successful)     
Enjoy!
